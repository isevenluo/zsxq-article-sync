# 知识星球文章同步

把链接（飞书文档、网页）或文字，排版后以「文章」形式发布到知识星球。

## 安装

在 WorkBuddy 对话里发送下面这句话：

> 安装这个 skill：https://github.com/isevenluo/zsxq-article-sync

AI 会自动拉取并安装。

## 使用

1. 第一次用：跟 AI 说"同步星球"，按提示告诉它要同步到哪个星球，并扫码授权「知识星球」连接器。
2. 之后：发链接 + 说"同步星球"，自动排版并以文章形式发布。

## 说明

- 每个使用者用自己扫码授权的账号，同步到自己的星球，互不影响。
- 知识星球没有官方开放 API，发布走网页版登录的 Cookie，偶发需要重新扫码。
- 以「文章」（长文）形式发布，不是普通帖子。
